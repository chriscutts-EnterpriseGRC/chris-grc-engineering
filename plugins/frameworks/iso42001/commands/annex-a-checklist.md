# Annex A Checklist — ISO/IEC 42001
Produces a full Annex A organisational controls checklist mapped to UCF controls with current effectiveness status and evidence requirements.
## Arguments
- `$1` - Filter: all | gap | effective (default: all)
- `$2` - Output format: markdown | json (default: markdown)
