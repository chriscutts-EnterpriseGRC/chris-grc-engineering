# Assess — NIST AI RMF
Maps current UCF AI controls to GOVERN / MAP / MEASURE / MANAGE subcategories, scores coverage, and identifies gaps.
## Arguments
- `$1` - Scope: all | govern | map | measure | manage (default: all)
## Output
Per-function scorecard with subcategory coverage %, gap list, and recommended remediation priority.
